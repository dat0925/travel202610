# 旅行先検討マップ

旅行先を「位置関係」から検討するためのマップ集。上部のタブで2つのマップを切り替えられます。

| マップ | 内容 |
| --- | --- |
| **那須ハイランド周辺おすすめ宿**（`index.html`） | 栃木県那須のペンション候補7軒と最寄り高速ICの位置関係。2026年10月の結婚20周年旅行向け。 |
| **関東 プールで遊べる宿マップ**（`pool.html`） | 埼玉県新座市から車3時間圏内で、プールで遊べる宿・施設14ヶ所。大人2名＋9歳（132cm）想定。 |

| ファイル | 内容 |

`data/*.js` は `file://` でも読めるように `.json` から生成した同内容のファイルです。

## 那須マップ 調査結果の要点

- **候補7軒すべて、最寄りICは「那須IC」**。那須高原スマートIC・黒磯板室ICはいずれも遠回りになるため、
  実質的な玄関口は那須IC 1ヶ所に絞れる。
  - 唯一の例外に近いのがモンゴリアビレッジ テンゲルで、那須ICと那須高原スマートICがどちらも9.2km
    （所要はスマートICが2分長い）。北（福島・白河）方面から向かう場合はスマートICも選択肢になる。
- 那須ICからの所要時間は **6分〜20分**。
  最短はガストホフ那須花（4.5km・6分）、最長は合歓林オリエンタル（16.2km・20分）。
- 候補は立地で2グループに分かれる。
  - **那須街道沿い・IC至近**：ガストホフ那須花／モンゴリアビレッジ テンゲル／ペンション散歩道
  - **那須ハイランドパーク側の別荘地（西寄り）**：ペンションローレル／アズール／合歓林オリエンタル
  - ペーパームーンは湯本寄りで、那須湯本方面の観光起点としては最短（殺生石まで5分）。

## データの作り方

- **宿の座標**：OpenStreetMap（Nominatim）に施設名で登録がある6軒はその座標を使用。
  国土地理院の住所検索APIは枝番（`1863-52` の `-52` 部分）を丸めるため、補助的な確認にのみ使用。
- **ペーパームーン那須は座標が非公開**のため、推定ピンは置かず、
  公称の「バス停『一軒茶屋』から徒歩約7分」に基づく**半径600mの円**で概略位置を表現している。
  距離・所要時間もバス停基準の参考値。
- **ICの起点**：高速本線ではなく、各ICが接続する一般道側の地点を起点にしている
  （那須IC＝那須高原線バイパス／那須高原スマートIC＝那須高原スマートインター線／黒磯板室IC＝黒磯板室インター線）。
  本線上の座標を起点にすると経路計算が高速道路を経由して大回りするため。
- **距離・所要時間**：OSRM（OpenStreetMapベースの経路計算エンジン）の自動車プロファイルによる算出値。
  渋滞・季節要因は含まない。
  検証として、公称「那須ICより12分」のペンション散歩道は算出12分、
  公称「3km・5分」のガストホフ那須花は4.5km・6分と整合した。

## プールマップ 調査結果の要点

前提：起点は埼玉県新座市、家族は大人2名＋9歳（身長132cm）、車で3時間が限界。
「宿泊施設内のプール」だけでなく「近くにプール施設がある宿」も対象とし、屋内（通年）と夏季限定の両方を掲載。

- **候補14ヶ所すべてが3時間圏内**。最遠のスパリゾートハワイアンズが169分・201kmで、渋滞を考えると実質ぎりぎり。
- **10月の那須旅行でも泳げる（屋内プールが通年）のは8ヶ所**。残る6ヶ所は夏季限定なので今シーズン中に行く必要がある。
- **この夏の本命は東武動物公園「東武スーパープール」（車51分）**。2026年に波のプールを開業以来初の大規模改修し
  「SAFARI COAST」としてリニューアルした年。8月31日まで連日＋9月の土日祝も営業。
- **泊まりでプール中心なら龍宮城スパ・ホテル三日月（車73分）**が最短。屋内「アクアパーク」が通年営業で
  ウォータースライダーと流れるプール、宿泊料金にプール利用が含まれる。
- **スライダー目的で季節を問わないなら箱根小涌園ユネッサン（車112分）**。「ロデオマウンテン」の大型
  ウォータースライダーは温水で冬でも滑れ、流れるプールは完全屋内。宿泊する「箱根小涌園 天悠」は
  専用連絡通路でユネッサンと直結（入場無料券付きプランあり）。
- **那須にはプールのある宿が3軒**（エピナール那須／グランドメルキュール那須高原／サンバレー那須）。
  ただし**10月に泳げるのは屋内温水プールのエピナール那須だけ**。グランドメルキュールのガーデンプールと
  サンバレーの屋外プールは夏季限定。グランドメルキュールからエピナール那須までは車7分（2.6km）で、
  プールだけ日帰り利用する手が使える。
- **那須の宿候補7軒はプールを持たないが、全軒が屋内プールのあるホテルまで車16分以内**
  （エピナール那須 5〜16分／サンバレー那須 2〜12分）。エピナール那須は日帰りで温泉＋プールが
  平日 大人1,500円・小学生1,000円。宿はペンション、プールは日帰りという組み合わせが成り立つ。
- **身長132cmは有利**。大型スライダーの制限は110〜130cmが多く、東京サマーランドでも130cmが分かれ目とされる。

### 除外した施設

- **ホテルリステル猪苗代**（福島県猪苗代町）：屋内プールはあるが車201分・254kmで3時間超。
- **さがみ湖リゾート プレジャーフォレスト／さがみ湖MORI MORI**：車75分と近いが、プールとして遊べる大型施設が確認できず
  （人気の「マッスルモンスター」は水を使わないクライミング施設）。

### プールマップのデータの作り方

- **起点**：新座市役所（埼玉県新座市野火止1-1-1）。国土地理院の住所検索APIで座標取得。
- **施設の座標**：OpenStreetMap（Nominatim）の施設名一致を優先し、国土地理院の住所検索と数百m以内で一致することを確認。
- **所要時間・距離**：OSRMの自動車プロファイル（高速道路利用）。**渋滞は含まない**ため、繁忙期は1.3〜1.5倍を見込む。
- **屋内プールが通年か**：営業期間の文章から推測すると誤判定しやすいため、施設ごとに `indoorYearRound` として
  明示的に持たせている。絞り込みの「屋内・10月も泳げる」「夏季限定」はこの値で切り替わる。
- **ルート形状**：地図描画用に約250m間隔へ間引き（14ヶ所で約103KB。間引かない場合は1MB超になる）。
- **Instagram**：アカウントの実在確認はログインが必要で判定できないため、推測したアカウント名は掲載していない。
  公式サイトに記載があって確認できた3件（@spa.resort.hawaiians / @tokyosummerland /
  @grandmercure_nasuhighlands）のみ公式リンクとして掲載し、
  それ以外はハッシュタグの「人気の投稿」ページへのリンクにしている。
