# 2026年10月 結婚20周年旅行計画

栃木県那須のペンション候補7軒について、**最寄りの高速道路インターチェンジからの位置関係**を
地図で確認できるようにまとめたものです。

## 中身

| ファイル | 内容 |
| --- | --- |
| `index.html` | 位置関係マップ本体（ブラウザで開くだけで動作） |
| `data/candidates.json` | 宿・IC・観光スポット・経路データの元データ |
| `data/candidates.js` | 上記を `window.CANDIDATES` として読み込むための生成物（`file://` 対応のため） |

`index.html` をブラウザで直接開けば地図が表示されます（地図タイルの取得にインターネット接続が必要）。

## 調査結果の要点

- **候補7軒すべて、最寄りICは「那須IC」**。那須高原スマートIC・黒磯板室ICはいずれも遠回りになるため、
  実質的な玄関口は那須IC 1ヶ所に絞れる。
  - 唯一の例外に近いのがモンゴリアビレッジ テンゲルで、那須ICと那須高原スマートICがどちらも9.2km
    （所要はスマートICが2分長い）。北（福島・白河）方面から向かう場合はスマートICも選択肢になる。
- 那須ICからの所要時間は **6分〜20分**。
  最短はガストホフ那須花（4.5km・6分）、最長は合歓林オリエンタル（16.2km・20分）。
- 候補は立地で2グループに分かれる。
  - **那須街道沿い・IC至近**：ガストホフ那須花／モンゴリアビレッジ テンゲル／ペンション散歩道
  - **那須ハイランドパーク側の別荘地（西寄り）**：ペンションローレル／アズール／合歓林オリエンタル
  - ペーパームーンは湯本寄りで、那須湯本方面の観光起点としては最短（殺生石まで5分）。

## データの作り方

- **宿の座標**：OpenStreetMap（Nominatim）に施設名で登録がある6軒はその座標を使用。
  国土地理院の住所検索APIは枝番（`1863-52` の `-52` 部分）を丸めるため、補助的な確認にのみ使用。
- **ペーパームーン那須は座標が非公開**のため、推定ピンは置かず、
  公称の「バス停『一軒茶屋』から徒歩約7分」に基づく**半径600mの円**で概略位置を表現している。
  距離・所要時間もバス停基準の参考値。
- **ICの起点**：高速本線ではなく、各ICが接続する一般道側の地点を起点にしている
  （那須IC＝那須高原線バイパス／那須高原スマートIC＝那須高原スマートインター線／黒磯板室IC＝黒磯板室インター線）。
  本線上の座標を起点にすると経路計算が高速道路を経由して大回りするため。
- **距離・所要時間**：OSRM（OpenStreetMapベースの経路計算エンジン）の自動車プロファイルによる算出値。
  渋滞・季節要因は含まない。
  検証として、公称「那須ICより12分」のペンション散歩道は算出12分、
  公称「3km・5分」のガストホフ那須花は4.5km・6分と整合した。
